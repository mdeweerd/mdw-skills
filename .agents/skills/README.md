# Rules for the skills of this repository

Every directory under `.agents/skills/` is one skill and must contain:

- `SKILL.md`: agentskills.io format, YAML frontmatter (`name`, `description`, `license`) followed by Markdown instructions. Written in English.
- `LICENSE`: the complete, unaltered Skill Protection License text. Mandatory. The license must be reproduced together with the skill at all times.

## Authoring rules

- Skills are generic: no reference to a specific company, project or client. Project-specific guidance belongs in a project-specific skill inside the target project, not here.
- All skills are written in English.
- Keep the `Validation` section of each skill accurate: it is the acceptance checklist for any change.
